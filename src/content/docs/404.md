If a page moved, the move is on the record. Two places to look:

- **[The changelog](/changelog/)** — every change, with the version it landed in.
- **[Git history](https://github.com/FlowBond-HQ/flowbond-docs/commits/main)** — the diff
  that renamed or removed it.

If you followed a link from an older version of the specification, check out that
version's git tag and read it there. The tag is the artefact of record; see
[how to audit](/audit/).
